# Versiones del mismo documento

Estos archivos comparten nombre pero **su contenido es distinto**: son
versiones reales, no copias, y por eso NO se borro ninguna. Lo que si
hace falta es saber cual leer.

**La marcada como VIGENTE es la version que contiene a las demas.** Las
fechas de archivo no sirven para decidir (el zip de traslado las reescribio
todas al mismo dia), asi que se compara el texto: estos documentos crecen
anadiendo secciones encima, de modo que la version que incluye lo de las
otras es la ultima. A igualdad decide la ubicacion — el documento vivo del
repo o de la carpeta de trabajo gana al snapshot de un paquete de
conocimiento o del envio a Kimi.

Las marcadas como historico sirven para ver como evoluciono una decision,
no para trabajar sobre ellas. **Si vas a editar, edita la VIGENTE.**
