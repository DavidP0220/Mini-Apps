Red de Canales de Abundancia

Montar el estudio en tu PC

Todo el proyecto vive en GitHub. En tu equipo se instala en unos minutos y a partir de ahí produce los videos sin límite de tiempo ni de disco.

Por qué conviene hacerlo en tu PC. La sesión en la nube se suspende sola y corta los renders largos. En tu equipo lanzas el lote de noche y a la mañana están listos. Además ahí sí puedo abrir tu navegador y tus aplicaciones cuando trabajemos juntos.

Lo que hay que instalar

Tres cosas, una sola vez. Copia y pega cada línea en la terminal (en Windows, PowerShell).

1

Git — para traer el proyecto

Windows:

winget install Git.Git

Mac:

brew install git
2

ffmpeg — el motor de audio y video

Es lo que arma los bucles de 8 horas y renderiza. Sin esto nada funciona.

winget install Gyan.FFmpeg

Mac:

brew install ffmpeg
3

Python y Pillow — miniaturas y animación

Descarga Python desde python.org marcando «Add to PATH», y después:

pip install Pillow

Traer el proyecto

Una sola vez. Descarga los scripts, el catálogo y toda la materia prima.

git clone https://github.com/DavidP0220/Mini-Apps
cd Mini-Apps
git checkout claude/proyecto-profesional-ingresos-7tx4aw
cd abundancia-canales

Comprobar que todo quedó bien

Estos tres comandos deben responder con una versión, no con un error.

ffmpeg -version
python --version
python -c "import PIL; print('Pillow ok')"

Producir el primer video

Copia la música y las imágenes desde el archivo, y lanza los cuatro pasos.

python scripts/03_audio.py --id lakshmi-01 --base assets/origen/musica/lakshmi-01.wav
python scripts/04_video.py --id lakshmi-01
python scripts/06_miniatura.py --id lakshmi-01 --img assets/origen/img/lakshmi-01-1.jpg
python scripts/08_short.py --id lakshmi-01 --seg 45

Producir todo el canal de una vez

Este es el que vas a usar de verdad. Lo lanzas de noche y trabaja solo: si algo falla lo anota y sigue, si lo interrumpes retoma donde iba, y se detiene antes de llenar el disco.

python scripts/05_lote.py --canal lakshmi --lluvia -19

Las opciones que cambian la calidad

OpciónQué haceCuándo usarla
--profundidadParalaje, luz volumétrica y partículas en dos planosVideos ancla y Shorts
--negroPantalla negra real para dormirVideos de 3 h o más
--lluvia -19Capa de lluvia sintetizadaTodo el contenido de sueño
--prueba 60Renderiza solo 60 segundosSiempre, antes del render final
--4kSale en 3840×2160Solo si tu PC lo aguanta

Consejo que ahorra horas. Antes de lanzar un video de 8 horas, corre siempre --prueba 60. Renderiza un minuto y te deja escuchar la mezcla y el volumen de la frecuencia. Media hora de CPU se pierde rápido cuando la lluvia quedó demasiado alta.
