# canal/ — buzón público de handoffs para Kimi

> **Esto NO es el proyecto del canal.** Aquí solo viven los handoffs que Kimi Code tiene que
> poder leer desde un enlace.

El proyecto completo — agentes, base de conocimiento, archivo histórico, storyboards, código —
vive en el repositorio **privado** `DavidP0220/mindset-mechanics`, que es la **fuente única de
verdad** desde el 2026-08-27 (decisión D-11). Si algo de aquí contradice algo de allá, manda allá.

## Por qué existe este buzón
Kimi Code no tiene git, ni disco, ni cuenta de Google. Hasta ahora, cada handoff dependía de que
David lo arrastrara a mano al chat de Kimi. Como este repositorio es **público**, Kimi puede leer
los handoffs abriendo un enlace, y esa dirección deja de depender de David (decisión D-13).

## Qué puede entrar aquí, y qué no
Las reglas duras están en `puente-kimi/BUZON_PUBLICO.md` y no son negociables. En resumen:
**solo el handoff**, nunca la base de conocimiento, el archivo, las métricas ni el código. Y
nunca claves, correos, identificadores de cuenta ni nombres de canal sin registrar.

Todo lo que se publique aquí es legible por cualquiera. Es el precio aceptado a cambio de
coordinarse con Kimi sin intermediario.
