# HALLAZGOS

Una ficha por hallazgo: `HALLAZGO-NNNN-<tema>.md`.
Numeración correlativa que **nunca se reutiliza**, ni siquiera si la ficha se descarta — una
ficha descartada sigue diciendo que ese camino ya se exploró.

La plantilla y las cinco condiciones de admisión están en
`../../protocolos/PROTOCOLO_INVESTIGACION.md`.

Resumen de las condiciones: **fuente + fecha**, **número + tamaño de muestra**, **verificado en
la fuente real**, **dice qué confirma o contradice**, y **termina en una recomendación cerrada**
(adoptar / probar con presupuesto X / descartar y por qué).

*Todavía no hay fichas: entran con la primera ronda de investigación.*
